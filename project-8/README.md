In this project, I implemented the Heston stochastic volatility model in Python. To mathematically address the violation of the Feller condition, I developed an Euler-Maruyama Monte Carlo simulation incorporating the Full Truncation Scheme for numerical stability. The analysis compares the Heston terminal distribution against the Black-Scholes log-normal benchmark, illustrating how the model captures the leverage effect via negative correlation and reproduces the implied volatility skew. The repository also features a semi-analytical pricing engine based on Fourier inversion (Characteristic Function) using Simpson's rule, demonstrating its superior precision and computational efficiency compared to Monte Carlo estimators.
